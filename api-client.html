How ytfarm uses YouTube API Services

API client documentation · 28 October 2026

ytfarm is a private command-line tool. Its only user is its owner, and it only acts on YouTube channels the owner owns. It has no public website, no sign-up and no screens that show YouTube data to anyone. This page describes exactly what it does with YouTube API Services.

Sign-in

  • Each channel is connected once with Google's OAuth 2.0 flow for limited-input devices: the tool shows a code, the owner enters it at google.com/device, picks the channel and approves access.
  • Scope requested: https://www.googleapis.com/auth/youtube (needed for uploads, schedules, thumbnails and playlists on the owner's channels).
  • The refresh token is stored encrypted in the owner's private repository. The owner can revoke it at any time in their Google account settings, or with the tool's disconnect command.
  • The tool refuses to connect two of its channels to the same YouTube channel, and checks before every upload that the login still opens the expected channel.

Publishing a video

  1. The owner prepares a plan: video files, titles, descriptions, tags and thumbnails.
  2. Dry run. The tool reads the channel's own scheduled uploads and shows the owner which release slot each video would get. Nothing is uploaded.
  3. Owner approval. Only after the owner approves does the tool upload.
  4. Each video is uploaded as private with a scheduled release time (status.publishAt), made-for-kids declared, and altered or synthetic content disclosed when it applies.
  5. The tool sets the thumbnail, adds the video to the channel's playlist, and reads the video back to confirm YouTube kept the schedule.

At most one long-form video and five Shorts a day per channel, matching each channel's publishing schedule.

API methods used

  • videos.insert (resumable upload): upload the owner's video, private with a release time.
  • thumbnails.set: the owner's custom thumbnail.
  • playlistItems.insert, playlists.list, playlists.insert: add the video to the owner's playlist (created once if missing).
  • channels.list (mine=true): confirm which channel the login opens and find its uploads playlist.
  • playlistItems.list, videos.list: read the owner's own recent uploads and their schedule, to find free release slots and confirm each upload.

What ytfarm never does

  • It does not access other people's channels, comments, messages, subscribers or analytics.
  • It does not show, store, sell or share YouTube data with anyone; it keeps only the encrypted sign-in and a log of its own uploads (video IDs, titles, links and times).
  • It does not like, comment, subscribe, or take any action on YouTube other than publishing the owner's own videos.
  • It never uploads without the owner's explicit approval.
